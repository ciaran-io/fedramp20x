# Orrinwick brand guidelines

> FICTIONAL DEMO DOCUMENT. Orrinwick Labs, Inc. is invented.

## Idea

"Orrin" is an old given name. "-wick" is the English place-name ending for a settlement or outpost, and a wick is also what you light. The brand is a dependable outpost that sends up a signal. The tone is calm, plain and exact. Orrinwick sells a service that people rely on at 3 a.m., so the design avoids alarm colours except for real faults.

## Mark

A rounded square in ink blue holds a small amber point with three arcs that fade outward, standing on a short base line. The point is the alert source. The arcs are the signal reaching a person. File: `trust-center/brand/logo-mark.svg`.

The wordmark is "Orrinwick" in Space Grotesk, weight 600, set beside the mark. Product names follow in a lighter weight, for example "Orrinwick Beacon" and "Trust Center".

Clear space around the mark equals the width of the base line. The minimum size is 20 px.

## Colour

| Name | Light | Dark | Use |
|---|---|---|---|
| Ink | `#0E1A2B` | `#0A121E` | Mark tile, page ground in dark theme, headings |
| Signal | `#F2A33A` | `#F2A33A` | Mark, one accent per screen, focus rings |
| Mist | `#F5F7FA` | `#111C2C` | Page ground in light theme, card surface in dark theme |
| Slate | `#5B6878` | `#93A1B3` | Secondary text |
| Pass | `#1F8A5B` | `#4CC38A` | Passing checks |
| Partial | `#B7791F` | `#E3B341` | Partial results |
| Fail | `#C23B3B` | `#F07178` | Failing checks |
| None | `#8A96A6` | `#6B7A8E` | No automated check yet |

Signal amber is the brand accent. Status colours carry meaning only and are never used for decoration.

## Type

- Headings: Space Grotesk, 600.
- Body: Inter, 400 and 500.
- Identifiers and code: JetBrains Mono.

## Voice

Plain, direct and specific. State what a control does and what evidence proves it. Mark simulated results as simulated.
